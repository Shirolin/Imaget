# Imaget : Sniffer d'images Web & Téléchargement par lot

Imaget est eine extension Chrome conçue pour simplifier le processus d'identification, de prévisualisation et de téléchargement d'images sur le Web. Elle offre une vue structurée dans le panneau latéral du navigateur et inclut des résolveurs spécialisés pour les principales plateformes afin de récupérer les sources d'images originales.

### Caractéristiques principales

*   **Sniffing d'images** : Détecte automatiquement les images sur la page actuelle et dans les contextes imbriqués (iframes).
*   **Adaptateurs spécifiques aux sites** : Inclut une logique intégrée pour Pixiv, Twitter (X), Weibo, Reddit et Telegram afin de mapper les miniatures détectées vers leurs sources originales en haute résolution.
*   **Filtrage structuré** : Filtrage en temps réel par dimensions (largeur/hauteur), types de fichiers (JPG, PNG, WebP, SVG) et mots-clés.
*   **Interface intégrée** : Utilise le panneau latéral de Chrome pour offrir un espace de travail persistant qui reste visible pendant la navigation sans masquer le contenu principal de la page.
*   **Respect de la vie privée** : Toutes les opérations de détection et de téléchargement sont effectuées localement. Aucune donnée utilisateur n'est collectée, stockée ou transmise à des serveurs externes.

### Mode d'emploi

1. Cliquez sur l'icône de l'extension pour ouvrir le panneau latéral.
2. Les images détectées s'affichent dans la liste au fur et à mesure de votre navigation.
3. Utilisez la barre d'outils pour appliquer des filtres de dimensions ou rechercher des éléments spécifiques.
4. Sélectionnez les images souhaitées et cliquez sur « Télécharger » pour les enregistrer en lot.
