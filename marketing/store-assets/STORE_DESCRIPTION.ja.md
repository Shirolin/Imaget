# Imaget：Web画像スニッファー＆一括ダウンローダー

Imagetは、ウェブ画像の識別、プレビュー、ダウンロードプロセスを簡素化するために設計されたChrome拡張機能です。ブラウザのサイドパネルに構造化された画像ビューを提供し、主要なプラットフォームのオリジナル画像を解析する機能を備えています。

### 主な機能

*   **画像スニッフィング**：現在のページおよびネストされたフレーム（iframe）内の画像アセットを自動的に検出します。
*   **プラットフォーム専用アダプター**：Pixiv、Twitter (X)、Weibo、Reddit、Telegram向けの解析ロジックを内蔵。検出されたサムネイルを元の高解像度リンクに自動的にマッピングします。
*   **構造化フィルタリング**：画像の幅、高さ、ファイル形式（JPG, PNG, WebP, SVG）、およびキーワードによるリアルタイムの絞り込みをサポート。
*   **サイドパネル統合**：Chrome Side Panelインターフェースを利用し、ウェブサイトの閲覧を妨げることなく、独立した操作スペースで画像を選択できます。
*   **プライバシー保護**：すべての処理はローカルで実行されます。本拡張機能は、ユーザーデータや閲覧履歴を収集、保存、またはアップロードすることはありません。

### 使用方法

1. ツールバーのアイコンをクリックしてサイドパネルを開きます。
2. ウェブサイトを閲覧すると、サイドパネルに検出された画像がリアルタイムで表示されます。
3. ツールバーを使用して、サイズフィルタリングや特定の内容の検索を行います。
4. 必要な画像を選択し、「ダウンロード」をクリックして一括保存します。
