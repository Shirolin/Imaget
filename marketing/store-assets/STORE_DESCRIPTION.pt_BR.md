# Imaget: Sniffer de Imagens Web e Download em Lote

Imaget é uma extensão do Chrome projetada para simplificar o processo de identificação, visualização e download de imagens da web. Oferece uma visualização estruturada no painel lateral do navegador e inclui resolvedores especializados para as principais plataformas para obter as fontes originais das imagens.

### Recursos Principais

*   **Sniffing de Imagens**: Detecta automaticamente recursos de imagem na página atual e em contextos aninhados (iframes).
*   **Adaptadores Específicos**: Inclui lógica integrada para Pixiv, Twitter (X), Weibo, Reddit e Telegram para mapear miniaturas detectadas para suas fontes originais em alta resolução.
*   **Filtragem Estruturada**: Filtragem em tempo real por dimensões (largura/altura), tipos de arquivo (JPG, PNG, WebP, SVG) e palavras-chave.
*   **Interface Integrada**: Utiliza o Painel Lateral do Chrome para fornecer um espaço de trabalho persistente que permanece visível durante a navegação sem obstruir o conteúdo principal da página.
*   **Foco na Privacidade**: Todas as operações de detecção e download são realizadas localmente. Nenhum dado do usuário é coletado, armazenado ou transmitido para servidores externos.

### Como Usar

1. Clique no ícone da extensão para abrir o painel lateral.
2. As imagens detectadas aparecerão na lista enquanto você navega.
3. Use a barra de ferramentas para aplicar filtros de dimensão ou buscar itens específicos.
4. Selecione as imagens desejadas e clique em "Download" para salvar em lote.
