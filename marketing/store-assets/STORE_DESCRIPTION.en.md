# Imaget: Web Image Sniffer & Batch Downloader

Imaget is a Chrome extension designed to streamline the process of identifying, previewing, and downloading images from the web. It provides a structured view within the browser's side panel and includes specialized universal sniffing for any website with deep resolvers for original high-res images.

### Key Features

*   **Image Sniffing**: Automatically detects image assets across the current page and nested contexts (iframes).
*   **Site-Specific Resolvers**: Includes built-in logic for Pixiv, Twitter (X), Weibo, Reddit, and Telegram to map detected thumbnails to their original, high-resolution sources.
*   **Constraint-Based Filtering**: Real-time filtering by dimensions (width/height), file types (JPG, PNG, WebP, SVG), and text patterns.
*   **Integrated UI**: Utilizes the Chrome Side Panel to provide a persistent workspace that stays visible while navigating without obscuring the main webpage content.
*   **Context Menu Support**: Quick-save any image as JPG, WebP, or PNG via the right-click menu, and easily access the side panel with a single click.
*   **Privacy-Focused**: All detection and downloading operations are performed locally. No user data is collected, stored, or transmitted to external servers.

### How to Use

1. Click the extension icon or use the context menu to open the side panel.
2. Detected images will appear in the list as you browse.
3. Use the toolbar to apply dimension filters or search for specific items.
4. Select the desired images and click "Download" to save them in bulk.
