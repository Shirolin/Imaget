# Imaget: Sniffer de imágenes web y descargador por lotes

Imaget es una extensión de Chrome diseñada para simplificar el proceso de identificación, vista previa y descarga de imágenes de la web. Proporciona una vista estructurada en el panel lateral del navegador e incluye resolutores especializados para las principales plataformas con el fin de obtener las fuentes de imagen originales.

### Características principales

*   **Sniffing de imágenes**: Detecta automáticamente activos de imagen en la página actual y en contextos anidados (iframes).
*   **Adaptadores específicos del sitio**: Incluye lógica integrada para Pixiv, Twitter (X), Weibo, Reddit y Telegram para vincular las miniaturas detectadas con sus fuentes originales de alta resolución.
*   **Filtrado estructurado**: Filtrado en tiempo real por dimensiones (ancho/alto), tipos de archivos (JPG, PNG, WebP, SVG) y patrones de texto.
*   **Interfaz integrada**: Utiliza el Panel lateral de Chrome para proporcionar un espacio de trabajo persistente que permanece visible mientras navega sin oscurecer el contenido principal de la página web.
*   **Privacidad garantizada**: Todas las operaciones de detección y descarga se realizan localmente. No se recopila, almacena ni transmite ningún dato del usuario a servidores externos.

### Cómo usar

1. Haga clic en el icono de la extensión para abrir el panel lateral.
2. Las imágenes detectadas aparecerán en la lista mientras navega.
3. Use la barra de herramientas para aplicar filtros de dimensiones o buscar elementos específicos.
4. Seleccione las imágenes deseadas y haga clic en "Descargar" para guardarlas en lote.
