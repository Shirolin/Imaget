# Imaget：網頁圖片嗅探與批量下載工具

Imaget 是一款為 Chrome 瀏覽器設計的圖片提取工具，旨在簡化網頁圖片的識別、預覽與下載流程。它通過集成的側邊欄介面提供結構化的圖片展示，並支持主流社交平台的原圖解析。

### 主要功能

*   **圖片嗅探**：自動探測當前網頁及嵌套框架（iframe）中的圖片資源。
*   **平台解析適配**：內置針對 Pixiv、Twitter (X)、Weibo、Reddit 及 Telegram 的解析邏輯，自動尋找原始高解析度連結。
*   **結構化過濾**：支持基於圖片寬度、高度、檔案格式（JPG, PNG, WebP, SVG）以及關鍵字的即時篩選。
*   **側邊欄交互**：利用 Chrome Side Panel 介面提供獨立操作空間，在不干擾網頁主體內容的前提下挑選圖片。
*   **隱私保護**：所有邏輯均在本地執行。本擴充功能不收集、不存儲也不上傳任何用戶數據或瀏覽記錄。

### 使用說明

1. 點擊工具列圖標開啟側邊欄。
2. 瀏覽網頁時，側邊欄將同步顯示探測到的圖片。
3. 使用工具列設置尺寸過濾或搜索特定內容。
4. 勾選圖片並點擊「下載」即可保存。
