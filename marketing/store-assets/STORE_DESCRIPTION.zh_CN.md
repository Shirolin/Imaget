# Imaget：网页图片嗅探与批量下载工具

Imaget 是一款为 Chrome 浏览器设计的图片提取工具，旨在简化网页图片的识别、预览与下载流程。它通过集成的侧边栏界面提供结构化的图片展示，并支持主流社交平台的原图解析。

### 主要功能

*   **图片嗅探**：自动探测当前网页及嵌套框架（iframe）中的图片资源。
*   **平台解析适配**：内置针对 Pixiv、Twitter (X)、Weibo、Reddit 及 Telegram 的解析逻辑，自动寻找原始高分辨率链接。
*   **结构化过滤**：支持基于图片宽度、高度、文件格式（JPG, PNG, WebP, SVG）以及关键词的实时筛选。
*   **集成化 UI**：利用 Chrome Side Panel 接口提供独立操作空间，在不干扰网页主体内容的前提下挑选图片。
*   **右键增强交互**：支持通过右键菜单一键将图片另存为 JPG、WebP 或 PNG 格式，并可快速从右键菜单唤起侧边栏。
*   **隐私保护**：所有逻辑均在本地执行。本扩展不收集、不存储也不上传任何用户数据或浏览记录。

### 使用说明

1. 点击工具栏图标或通过网页右键菜单开启侧边栏。
2. 浏览网页时，侧边栏将同步显示探测到的图片。
3. 使用工具栏设置尺寸过滤或搜索特定内容。
4. 勾选图片并点击“下载”即可保存。
