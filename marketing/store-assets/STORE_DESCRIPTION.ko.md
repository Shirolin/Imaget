# Imaget: 웹 이미지 스니퍼 및 일괄 다운로더

Imaget은 웹 이미지의 식별, 미리보기 및 다운로드 프로세스를 간소화하기 위해 설계된 Chrome 확장 프로그램입니다. 브라우저의 사이드 패널을 통해 구조화된 이미지 뷰를 제공하며, 주요 플랫폼의 원본 이미지 해석 기능을 지원합니다.

### 주요 기능

*   **이미지 스니핑**: 현재 페이지 및 중첩된 프레임(iframe) 내의 이미지 자산을 자동으로 감지합니다.
*   **플랫폼별 어댑터**: Pixiv, Twitter (X), Weibo, Reddit 및 Telegram을 위한 전용 해석 로직을 내장하여, 감지된 썸네일을 원본 고해상도 링크로 자동 매핑합니다.
*   **구조화된 필터링**: 이미지 너비, 높이, 파일 형식(JPG, PNG, WebP, SVG) 및 키워드 기반의 실시간 필터링을 지원합니다.
*   **사이드 패널 통합**: Chrome Side Panel 인터페이스를 활용하여 웹 페이지 콘텐츠를 가리지 않고 독립적인 작업 공간에서 이미지를 선택할 수 있습니다.
*   **개인정보 보호**: 모든 로직은 로컬에서 실행됩니다. 본 확장 프로그램은 어떠한 사용자 데이터나 브라우징 기록도 수집, 저장 또는 전송하지 않습니다.

### 사용 방법

1. 툴바 아이콘을 클릭하여 사이드 패널을 엽니다.
2. 웹서핑 시 사이드 패널에 감지된 이미지 목록이 실시간으로 업데이트됩니다.
3. 툴바를 사용하여 크기 필터링이나 특정 내용을 검색합니다.
4. 원하는 이미지를 선택하고 '다운로드'를 클릭하여 일괄 저장합니다.
